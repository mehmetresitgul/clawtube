# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the work.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull
requests or any other project space.

## Reporting

If someone's behaviour in this project makes you uncomfortable, report it privately to the
maintainer through GitHub (for example with a [private report](https://github.com/mehmetresitgul/clawtube/security/advisories/new)
or a direct message on GitHub) instead of a public issue. Reports are kept confidential, and the
maintainer may remove content or block participants who break these rules.
